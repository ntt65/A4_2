# src/ 구현 규칙

- 모든 함수의 매개변수와 반환값에 타입 힌트를 명시한다.
- 패턴 매칭·텍스트 추출·마스킹에는 Python 내장 re만 사용한다.
- 각 정규식 바로 위에 대상·의도·매칭 범위와 오탐·미탐을 막는 경계 조건을
  주석으로 설명한다. 이메일·전화번호·날짜·금액·URL별 경계를 구분하고,
  사용한 ^, $, \b, lookahead/lookbehind의 역할을 명확히 한다.
- 감성 점수와 함께 매칭된 긍·부정 토큰 및 가중치를 반환한다.
- Precision·Recall·Accuracy·F1 계산에서 분모가 0인 경우를 방어한다.
