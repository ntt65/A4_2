## 기존 구현 계획

다음 문단과 표는 [회의록 2절](meeting-notes/2026-11-15-a4-2-agentic-engineering.md#2-미션-계획과-구현-결과)의 계획을 복사했다. 표 안의 이슈 상태는 회의록 작성 당시 기록이다.

[미션 문서](A4_2_mission.md)는 Python 3.10 이상과 내장 `re`를 사용한 규칙 기반 NLP 파이프라인을 요구한다. 이메일·전화·날짜·금액·URL의 변형을 각각 3가지 이상 처리하고 결과를 정규화한다. 정보 추출은 50문장 이상, 패턴별 10문장 이상으로 정밀도·재현율을 측정하고 실패 5건 이상을 분석한다. 감성은 일반 사전 200단어 이상, 도메인 30단어 이상, 라벨 문장 100개 이상을 준비한다. 부정어·강조어·이중부정 규칙을 적용하고 정확도·F1의 규칙 전후 변화와 오분류 10건 이상의 원인을 기록한다. 마스킹은 미션의 보너스 항목이며 A4_2 구현 범위에 포함됐다.
