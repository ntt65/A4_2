## 사용자 목표와 적용안

- AI 입력·캐시 사용량과 불필요한 호출을 줄인다. 사용자는 다른 리포에서 `index.md`, `reverse_index.md`를 활용해 왔으며 A4_2에는 아직 작성하지 않았다.

- 상세 결과·로그는 로컬 파일에 보관하고 성공 요약 또는 필요한 실패 부분만 읽는다. 독립 명령을 묶고 상태 재조회·장황한 진행 보고를 줄인다. 관련 변경이 없으면 통과한 검증을 반복하지 않는다.

- 로컬 파일 저장 자체는 LLM 토큰을 쓰지 않는다. 모델이 읽은 내용·생성한 요약은 사용량에 포함된다. 서버 KV 캐시를 사용자 PC로 옮기는 기능과는 다르다.
