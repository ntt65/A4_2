# Documentation Local Agent Guidelines (`docs/`)

## 1. 문서 갱신 트리거 및 동기화 원칙
- PR 생성 시점이 아니라 `src/` 로직 수정, 정규식 패턴 변경, 또는 `data/` 테스트셋 갱신 작업이 완료될 때마다 관련 문서를 즉시 동기화한다.
- 실행 지표(`Precision`, `Recall`, `Accuracy`, `F1`)가 변동되면 문서 내 표와 수치를 최신 실행 결과로 덮어쓴다.

## 2. 문서 작성 표준
- **실패/오분류 사례 분석**: 단순 현상 나열이 아니라 `[입력 문장] -> [기대 결과] vs [실제 결과] -> [규칙 한계 원인]` 구조로 작성한다.
- **표기 규칙**: 모든 수식 및 지표 설명 시 가독성을 위해 텍스트와 기호 간 간격을 명확히 구분하고, 외부 감성 사전 출처 및 라이선스를 명시한다.
